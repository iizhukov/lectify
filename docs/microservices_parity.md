# Что переносим из монолита

Эталон функций — old_monolit. Старый код нужен для сравнения;
новые сервисы не должны импортировать его при запуске.

Нужно проверить весь путь:
пользователь → файл → workflow → обработка → сохранённый результат.
Каждый RPC должен проверять доступ пользователя к данным.

Не завершены:
- profile, personal и правила использования LLM;
- media converter, prompt selector, LaTeX и PDF;
- автоматический запуск агентов с сертификатами;
- восстановление после сбоев и управление повторными попытками;
- полный запуск приложения и работа нескольких реплик;
- интерфейс и клиентский HTTP API (позже).

Наличие protobuf, манифеста или unit-теста не означает готовность сценария.
Нужны проверки реального запуска, хранения результата и отказов.
